# Reference definitions

From the same Taylor-expanded u_i, K is the Hessian and the fixed-site legacy S={sum_i r_i(z*)h0_i,H0}; the old candidate is J+map(S)-S. S can contain affine momentum terms and must not be reduced to a bilinear. The moving-flow alternative forms {sum_i r_i(z)h0_i,H0}, shifts z=z*+dz, extracts the exact homogeneous dz*velocity sector H (row displacement, column velocity), and maps that sector alone: J+dz^T[map(H)-H]zdot. They are distinct quantities; bridge returns both explicitly. The parent observed for frozen tilted left reference S linear pq coefficient 0.004752558268185714 and pQ -0.0018750000000005151, with different moving bilinear coefficients; these are review observations, not new independent test outputs.

For W=G^-1/2, W K W=E diag(omega^2) E^T, T=W E, the map substitutes z=z*+T xi and p=T^-T Pi, calls the existing `oho.harmonic_map`, then substitutes xi=T^-1(z-z*), Pi=T^T p. Thus H_mode=T^T H T, including nonsymmetric H and both mode orders. The existing map operates in ladder variables and treats sum/difference frequencies through sinhc, including its small-argument branch; beta*hbar->0 tends to identity. Our tests cover the classical limit and legacy frozen cases, but independent degenerate and full frequency-grid mapping controls remain outstanding. Negative-curvature references are rejected, not made positive by absolute value.

## Modal kernel correspondence

For each mode a define b_a=beta*hbar*omega_a and f_a=b_a/[2 sinh(b_a/2)]. The reused ladder-polynomial map expands a normal Weyl monomial into powers u_a,v_a. For a contraction multi-index j, set r=u-j, s=v-j; the uncontracted factor is sqrt(sinhc((r-s) dot b / 2) times product f_a^(r_a+s_a)). Each contraction contributes j_a! binom(u_a,j_a) binom(v_a,j_a) [hbar*tanh(b_a/4)/2]^j_a. This is the actual `oho.harmonic_map` rather than an empirical scalar. For cross-mode quadratic ladder terms r-s has components ±1, hence the arguments contain (b_a+b_b)/2 and (b_a-b_b)/2. The `sinhc` small-argument branch gives the degenerate difference limit; f and the contractions give the classical beta*hbar limit. Non-symmetric transport requires preserving both row/column channels under T^T H T and the reverse transform. Independent numerical validation of all degenerate/rotated cases remains NOT RUN for this revision.
