# GPUMD diagnostic interface — source implemented, not compiled or run

Opt in with `compute_u9_oho diagnostic <config>` alongside exactly one `compute_hac` configured for immediate, unsplit centroid current. `candidate` fails explicitly: neither a material Cartesian operator nor physical acceptance exists. Without the action no U9 calculation or output is requested. WPE uses the existing HAC observer only after checking run-stage identity, charge mode, PPPM spacing, bead/atom counts and no DFTD3/Eco; this has not been compiled or run. RPMD and primitive fixed-temperature PIMD are selected in source, the latter a diagnostic rather than production RPMD result. A fixed timestep, no fixed/moving groups, no drive, three-dimensional PBC, one charge1/2 qNEP with PPPM and no DFTD3 are required.

The strict, ordered, whitespace-delimited v1 schema is illustrated by `tests/u9_oho/synthetic.cfg`. This is a non-production fixture with deliberately dummy fingerprints. All fields are mandatory; unknown/reordered/duplicate/trailing tokens fail. `coefficients` order is c0..c4,K,lambda0..lambda2; `r0` is atom-major L xyz, H xyz, R xyz; `images` are atom-major integer fractional-cell image vectors, with wrapped reference = R0 - cell*image and each fractional component in [0,1); `A` is nine atom-major Cartesian rows by two columns. Cell is the GPUMD row-major Cartesian matrix. `G=A^T M A`, `C=G^-1`, physical B*A=I and physical q,Q of R0=z0 are checked; e is fixed and unit. `left` and `right` must be ordered stable stationary points. `model_fnv` and `config_fnv` are unsigned decimal fingerprints from the existing RPMD-JA algorithms, not generic hashes. `source`, `reference` are whitespace-free identity tokens; site gauge must be `constrained_v1`. Units: Å, eV, amu, K and GPUMD natural time.

At run initialization the three positions are anchored to frozen R0 and image vectors; subsequent steps use minimum fractional increments, requiring both each increment and cumulative displacement from R0 to stay strictly below 0.45 in every fractional direction. A restart explicitly reanchors to this same frozen branch; there is no hidden persistence and an ambiguous branch is rejected. Only 18 centroid scalars are gathered per step, followed by mass projection z=z0+C A^T M(R-R0), zdot=C A^T Mv and p=G zdot. The physical q,Q and Euclidean off-slice position and velocity residuals are output separately. `on_slice=1` means both residual norms are <=1e-8 in their respective Å and Å/natural-time units; this is a numerical label, not proof that the real trajectory is constrained.

`u9_oho_diagnostic.out` appends a versioned segment only after checking the previous file schema and terminated segments; each segment records run ordinal, reference-file fingerprint, identities, temperature, timestep and HAC interval. Rows contain local step (one-based), segment-local time `(step+1)*dt` in ps matching existing JA, and absolute global time in ps, projected state, U/gradient/Hessian, physical coordinates, residuals, status and Jc xyz from the same HAC frame. Velocity is Å/natural-time, p is amu Å/natural-time and Jc uses GPUMD current units. Existing JA and HAC outputs remain separate; no U9 heat current or conductivity is written. The action follows HAC and samples `(step+1)%sample_interval==0`. All runtime behaviour, schema, indexing and CUDA correctness remain NOT RUN until compiled and tested.

## Revised identity and safety contract

Configuration input is capped at 65536 bytes and a terminal I/O error is rejected. Selected positions/velocities must have exactly 3N GPU entries and the three atom symbols must be O,H,O; isotope D is encoded as H with the appropriate mass. Both native and WPE qNEP observer PPPM spacings must be finite. These changes and the extracted `u9_oho::project` helper are source-only and have not been compiled or executed. The segment-local clock and cumulative global clock remain distinct; earlier output schema is rejected if its column list differs.
