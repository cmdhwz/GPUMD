``<prefix>_atoms.out``
======================

Generated by :ref:`dump_interface_atoms <kw_dump_interface_atoms>`. The first line of metadata describes the geometry source and selected zero-based half-open bin window; the next metadata lines state units, indexing, sampling, and force semantics. Numeric rows have 17 columns:

::

   frame step time_ps atom_id x_A y_A z_A xu_A yu_A zu_A vx_A_ps vy_A_ps vz_A_ps fx_eV_A fy_eV_A fz_eV_A potential_eV

Each row contains one atom from the fixed reference mapping. Positions are in A, velocities in A/ps, forces in eV/A, and potential energy in eV. Both complete sample blocks and the final incomplete block are written after a successful run. The file is refused if it already exists.
